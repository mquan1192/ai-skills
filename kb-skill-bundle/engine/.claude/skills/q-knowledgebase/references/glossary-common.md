# Common technical vocabulary (EN / JA / VI)

Generic word list used by the glossary bridge of `search` / `query` when `"common_glossary": true` (default).
It holds everyday technical words only — no product, project or customer term. Project terms belong in the
project's own glossary file, declared with `glossary_paths` in `.qkb/config.json`. One row = one concept;
` / ` separates alternatives. Turn the list off with `"common_glossary": false`.
